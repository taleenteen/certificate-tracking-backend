# ระบบหลังบ้าน e-License

ระบบหลังบ้านสำหรับแพลตฟอร์มใบอนุญาตอิเล็กทรอนิกส์ รองรับข้อมูลบุคคลธรรมดา นิติบุคคล สถานประกอบการ ใบอนุญาต และการให้เจ้าหน้าที่เข้าถึงข้อมูลตามสิทธิ์ของตน ระบบให้บริการ API แก่เว็บแอปพลิเคชัน และเชื่อมต่อทางรัฐได้ทั้งรูปแบบ mToken และ OIDC ที่เลือกใช้ผ่านการตั้งค่า

## กลุ่มผู้ใช้งาน

- `public` ผู้ใช้งานทั่วไป ดูข้อมูลและจัดการข้อมูลของตนเอง
- `officer` เจ้าหน้าที่ ค้นหา ตรวจสอบ และส่งออกเอกสารตามสิทธิ์
- `supervisor` ผู้ควบคุมงานในหน่วยงาน
- `admin` ผู้ดูแลการปฏิบัติงาน
- `super_admin` ผู้ดูแลสูงสุด จัดการสิทธิ์และหน่วยงานได้ทั่วระบบ

## ฟีเจอร์หลัก

- ยืนยันตัวตนด้วยทางรัฐผ่าน mToken หรือ OIDC และรองรับบัญชีผู้ดูแลแบบรหัสผ่านกับ TOTP
- จัดการบัญชีผู้ใช้ สิทธิ์ หน่วยงาน และบริบทการใช้งานของนิติบุคคล
- เก็บข้อมูลสถานประกอบการ พิกัดแผนที่ ใบอนุญาต เอกสารประกอบ และสถานะอายุใบอนุญาต
- รองรับใบอนุญาตของนิติบุคคลโดยตรง และใบอนุญาตภายใต้สถานประกอบการ
- ค้นหาใบอนุญาตและสถานประกอบการแบบจัดกลุ่ม พร้อมข้อมูลเจ้าของหรือผู้ถือสิทธิ์
- ส่งออกเอกสารใบอนุญาตสำหรับเจ้าหน้าที่เป็น PDF, CSV และ XLSX พร้อมเลขอ้างอิงและประวัติการส่งออก
- เก็บไฟล์เอกสารแบบ private object storage บน MinIO และสร้างลิงก์ดาวน์โหลดชั่วคราว
- บันทึก Audit Log สำหรับการเปลี่ยนแปลงและการดำเนินการสำคัญ
- มีข้อมูลจำลองและสคริปต์ seed เพื่อใช้สาธิตระบบ รวมถึงเอกสารใบอนุญาตตัวอย่าง

## เทคโนโลยี

- NestJS 11 และ TypeScript
- PostgreSQL 16 และ Prisma 7
- MinIO สำหรับจัดเก็บเอกสาร
- Docker Compose สำหรับสภาพแวดล้อม local และ prototype production

## การตั้งค่าที่สำคัญ

ใช้ไฟล์ `.env` ที่โฟลเดอร์นี้สำหรับ backend ห้ามนำค่า secret หรือ private key ขึ้น Git

สำหรับ mToken UAT ต้องกำหนดค่าอย่างน้อย:

```env
DGA_MTOKEN_MODE=real
DGA_MTOKEN_ENV=uat
DGA_MTOKEN_CONSUMER_KEY=...
DGA_MTOKEN_CONSUMER_SECRET=...
DGA_MTOKEN_APP_ID=...
```

## การ Deploy แบบ Prototype

```bash
sh scripts/production-stack.sh up
```

คำสั่งนี้ build บริการทั้งหมดและให้ backend รัน Prisma migration อัตโนมัติ โดยจะ seed เฉพาะเมื่อฐานข้อมูลว่างเท่านั้น

```bash
sh scripts/production-stack.sh verify
```

ใช้ตรวจสอบ health ของบริการและจำนวนข้อมูลหลักในฐานข้อมูล หลีกเลี่ยงคำสั่ง `reset` หากต้องการเก็บข้อมูลเดิม เพราะคำสั่งดังกล่าวลบ Docker volumes ของฐานข้อมูลและ MinIO
